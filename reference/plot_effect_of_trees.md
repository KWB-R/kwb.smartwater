# Plot the Effect of Trees

Plot the Effect of Trees

## Usage

``` r
plot_effect_of_trees(
  block_code = "1100556171000000",
  max_vegetation_class = 80,
  n_trees = 0:100
)
```

## Arguments

- block_code:

  code of Berlin block. Default: "1100556171000000" (Bayerischer Platz)

- max_vegetation_class:

  maximal vegetation class. Default: 80

- n_trees:

  vector of tree numbers to be simulated. Default: 0:100
